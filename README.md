# 墨阅 MoYue

一个原生 Android 电子书阅读器，交互和排版对标 iBooks。

不是网页套壳，是真正的原生 App：用 Android 的 `StaticLayout` 做分页排版，`Canvas` 绘制页面，没有任何 WebView，也没有引入任何第三方库（整个 APK 590KB，其中五张纸张贴图占了 540KB，代码本身只有 60KB）。

**下载**：[Releases](../../releases) 里有打包好的 APK，仓库里也放了一份 `dist/墨阅-MoYue-v1.6.apk`。

---

## 安装

APK 文件：`dist/墨阅-MoYue-v1.6.apk`

1. 把 APK 传到平板（微信/QQ 传文件、数据线、U 盘都行）
2. 在平板上点开 APK 安装
3. 如果提示"未知来源"，允许一次即可

**系统要求**：Android 7.0 及以上（minSdk 24），支持手机和平板，横竖屏都适配。

## 功能

### 书库
- 导入 EPUB / TXT（支持一次选多本，也支持从文件管理器"用其他应用打开"直接导入）
- 格式自动识别，不靠扩展名，看文件内容
- 封面自动提取；没有封面的书（含所有 TXT）自动生成文字封面
- 显示阅读进度条和百分比角标，读完的标"已读完"
- 长按书本：开始阅读 / 修改书名 / 书籍信息 / 移除
- **修改书名**：网上下载的文件名经常很乱，可以自己起个名字（只改显示名，不动文件）
- 排序：最近阅读 / 导入时间 / 书名

### 阅读
- **原生分页**，按行高精确切页，不是滚动
- **仿真翻书**：跟 iBooks 同一套模型——页面绕一根"卷曲轴"弯成圆柱，用 `drawBitmapMesh` 做网格形变
  - 卷曲轴方向由拖动方向决定（轴 ⟂ 拖动方向），所以从中间往左拖和从屏幕下沿斜着拖，卷起来的样子不一样
  - 正面和纸背**都走网格**，边界严格等于纸张矩形的像，任何倾角都不会画到纸以外
  - 明暗按物理来：卷顶那圈纸竖直（掠射，最暗），翻过去平铺后正对视线（最亮）
  - 卷筒在底下那页投一道渐隐的影，影子的范围同样按纸面裁剪，倾斜时不会拖出多余的一条
  - **跟手拖动**：手指按住横向拖动，卷曲跟着手指走，松手后卷过三成就翻过去，不到三成弹回原页
  - 支持点击、滑动、音量键触发，同样走卷曲动画
- **朗读（TTS）**：调用系统语音引擎念正文
  - **六种音色**：原声 / 女声 / 男声 / 低沉男 / 少年 / 老人。系统 TTS 没有换音色的接口，靠音高区分（0.72–1.34，再往外就失真成电子音了）；如果平板里装了多个中文语音包，面板里会多出一行**语音包**，可以直接切真音色
  - **长按正文任意一段，就从那里开始念**：按下的那一段先亮一下（"就这儿"），随后从这一句开头起念，不会半句起头
  - **念到哪一句，画面就翻到哪一页、亮哪一句**：翻页和高亮是同一次动作，不会出现声音已经在下一页、高亮还留在上一页
  - **悬浮朗读条**常驻屏幕下方：`暂停 / 继续` 和 **`停止`** 都在明面上，不用长按翻菜单
  - 一章读完自动接下一章，全书读完提示
  - 点工具条按钮开始 / 暂停 / 继续，长按可选语速（0.8x–1.8x）或停止
  - 朗读时如果自己翻页，会自动暂停，免得声音和画面对不上；点「继续」从当前念到的那一句接着读
- 左右点击翻页（左 28% 上一页，右 28% 下一页），中间点击呼出工具栏
- 翻页效果可在排版面板切换：**翻书 / 滑动**
- 页眉显示章节名，页脚显示页码
- 音量键翻页
- 进度条拖动跳转全书
- 目录抽屉，支持多级目录，当前章节高亮
- 书签：点书签按钮收藏当前页，再点取消
- 退出自动记住读到哪一页

### 排版
- 字号 13–30，逐级可调
- 行距：紧凑 / 适中 / 宽松
- 字体：宋体（衬线）/ 黑体（无衬线）
- 背景：纸色 / 纯白 / 米黄 / 夜间（夜间模式状态栏图标自动反色）
- **纸张纹理**：无 / 木纹 / 亚麻 / 皮革 / 石纹 / 旧纸，和四种背景色任意组合
  - 贴图是 `tools/make_textures.py` 程序生成的（512×512，白色 RGB + alpha），平铺无缝，代码里按主题着色，所以一张图同时适配浅色纸和夜间模式
  - 强度压得很低（alpha 均值 0.03–0.13），只让纸有质感，不抢文字
- 页边距：窄 / 中 / 宽
- 翻页效果：翻书 / 滑动

### 格式支持
- EPUB 3（`nav.xhtml` 目录）
- EPUB 2（`toc.ncx` 目录，含多级嵌套）
- **TXT 纯文本**
  - 编码自动识别：UTF-8（含 BOM）/ UTF-16 / GBK / GB18030
  - 按"第X章""序章""楔子""番外""Chapter N"等标记自动切章
  - 认不出章节标记时，按篇幅（约 6000 字）自动分节，不会切在句子中间
  - 自动从正文开头识别"作者：xxx"
  - 段落识别：中文小说按"一行一段"处理，长行折行的文本按空行分段
- 中文编码自动识别（UTF-8 / GBK / GB18030）
- 章节内嵌图片（EPUB）
- 自动剥离 `<script>`，书里的脚本不会执行

## 项目结构

```
MoYue/
├── app/src/main/java/com/moyue/reader/
│   ├── MainActivity.java          书库界面
│   ├── ReaderActivity.java        阅读界面（工具栏/目录/排版面板）
│   ├── book/BookSource.java       书源统一接口（EPUB / TXT 都实现它）
│   ├── book/TxtBook.java          TXT 解析：编码识别、切章、分段
│   ├── book/TocEntry.java         目录项
│   ├── epub/EpubBook.java         EPUB 解析引擎
│   ├── ui/ReaderView.java         分页排版与绘制（核心）
│   ├── ui/CurlGeometry.java       仿真翻书的圆柱卷曲几何（纯数学，可桌面测试）
│   ├── text/TextRange.java        切句 / 段落边界 / 行→页映射（纯 Java，可桌面测试）
│   ├── tts/VoiceStyle.java        朗读角色（音高预设，纯 Java，可桌面测试）
│   ├── ui/PageCache.java          整页位图缓存（三槽 LRU，防回收正在用的位图）
│   ├── ui/BookAdapter.java        书架网格
│   ├── ui/CoverFrame.java         2:3 封面容器
│   ├── tts/SpeechReader.java      系统 TTS 封装：逐句朗读、进度回报
│   ├── db/LibraryDb.java          SQLite 书库
│   └── model/BookRecord.java
├── app/src/main/res/drawable-nodpi/   五张纸张纹理贴图（程序生成，不随屏幕密度缩放）
├── test/jvm/                      桌面端测试（203 项断言）
├── tools/run_tests.sh             一键跑测试
├── tools/                         图标 / 纹理 / 测试样本生成脚本
└── dist/                          打包好的 APK
```

阅读器本身不关心底下是什么格式——`ReaderView` 只认 `BookSource` 接口，加新格式只要再实现一个书源。

## 构建

需要 JDK 17 + Android SDK 34：

```bash
export JAVA_HOME=/path/to/jdk17
export ANDROID_HOME=/path/to/android-sdk
./gradlew assembleRelease
```

产物在 `app/build/outputs/apk/release/`。

签名配置不写在仓库里。要出正式签名包，在本机 `local.properties` 里加四行（该文件已被 `.gitignore` 排除）：

```properties
RELEASE_STORE_FILE=../your.jks
RELEASE_STORE_PASSWORD=******
RELEASE_KEY_ALIAS=your_alias
RELEASE_KEY_PASSWORD=******
```

没有这四行也能正常构建，只是 release 包会退化成未签名（`app-release-unsigned.apk`）。

## 测试

解析引擎和翻页几何都可以在桌面 JVM 上直接验证（不需要模拟器，也不需要 Android SDK）：

```bash
bash tools/run_tests.sh
```

输出：

```
CurlTest         通过 31 项，失败 0 项
ParseTest        通过 20 项，失败 0 项
ParseTest2       通过 13 项，失败 0 项
TxtTest          通过 26 项，失败 0 项
ReadTest         通过 56 项，失败 0 项
PageCacheTest    通过 17 项，失败 0 项
TextureTest      通过 40 项，失败 0 项
----------------------------------------
合计：通过 203 项，失败 0 项
```

脚本做的事就是 `javac` 编译"纯 Java 层 + `test/jvm/android/graphics` 桩"，然后逐个 `java -cp` 跑；想手动跑，看脚本里那条 `javac` 就行。

已覆盖（203 项断言）：
- EPUB3 元数据与 nav 目录、EPUB2 NCX 多级目录、封面查找、内嵌图片、GBK 编码、相对路径解析
- TXT 的 UTF-8/GBK 编码识别、章节切分、无标记时按篇幅分节、段落判定、HTML 转义
- 两种格式的自动识别与分发
- 卷曲几何：起点必须是一张平摊整页、终点纸必须整张卷出屏幕（否则收尾会闪）、卷曲角封顶 π、投影单调回落、前后翻互为倒放、卷曲轴随拖动倾角变化
- **倾斜角度专项**：纸面端点始终落在纸张矩形内（防止倾斜时纸背画到纸以外）、竖直折痕轮廓线贯穿整页、倾斜折痕轮廓线被边界截短、投影不会拉长轮廓线
- 朗读定位：切句不漏字/不重叠/不出空句、超长句按上限硬拆、任意字符位置都能定位到有效句子、段落边界始终夹住按下的位置
- **行→页映射**：二分结果与线性扫描对拍 2.2 万组随机用例；整章逐句扫一遍，页码只前进不后退、没有翻不到的页
- **位图缓存**：连续前翻/后翻各 60 帧、来回横跳、跳页、换版面，每一帧交出去的两张位图都不许被回收；缓存不膨胀；每帧最多新建一张
- **朗读角色**：音高都落在不失真的 0.7–1.4、相邻角色至少差 0.05（听得出区别）、原声必须真的是 1.0、越界 id 退回原声
- **纸张纹理**：五张都在且是 512×512 纯 alpha 图、RGB 全白、左右/上下接缝的跳变不大于图内部（平铺无缝）、够淡不抢字又够有存在感

生成测试样本：`python3 tools/make_sample_epub.py && python3 tools/make_sample_epub2.py && python3 tools/make_txt_samples.py`

重新生成纸张纹理：`python3 tools/make_textures.py`（需要 pillow + numpy）

## 已知限制

- 复杂 CSS 排版不生效（只保留标题、段落、粗斜体、图片等基本结构），这是原生排版的取舍
- 卷曲用单一半径的圆柱近似，不是真实纸张的螺旋卷（那要网格 + 光照方程，代价大得多）
- 翻书动画要缓存三张整页位图（本页 / 目标页 / 下一帧还要复用的那张，约 3×屏宽×屏高×4 字节）。只给两槽会每帧重建两张、翻页发卡；给三槽后每帧最多新建一张。极低端机器分配失败会自动退回滑动效果
- 朗读依赖系统 TTS 引擎，没装中文语音包时只能提示安装
- 不支持 PDF、MOBI、AZW3
- TXT 全文常驻内存，几十 MB 的超大文本可能吃紧
- 不支持高亮批注和跨书搜索
- 竖排（直排）暂不支持

## 说明

"移植 iBooks" 做不到——iBooks 是苹果闭源的。这个项目是照着它的交互和质感重做的独立实现。

纸张纹理全部由 `tools/make_textures.py` 程序生成，没有使用任何外部素材；图标同理（`tools/gen_icons.py`）。
